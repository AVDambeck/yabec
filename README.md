# Yet Another Basic/Expert Clone 
Yabec started as a way to codify the Old School Rennessance mix I was running at my table. It now is an open source project for others to work from. I'm very grateful for an amazing table, and for all the feedback they've given me.

# Direction
This is version 3.4! The main game is for the most part here and settled in. This most recent update is focused on retuning and rebalancing; tweaking pretty mich everything with a coin cost. Hirelings, travel, and combat will probably continue to be tweaked. 

Moving forward, I intend to focus on fleshing out domain play, and making premade character sheets and other resources.

## Suggestions
I'm always open to suggestions. Feel free to open an issue on GitHub, or reach out to me via email, discord, signal, matrix, irl, or any other platform you know me through.

# Features
What kind of system is yabec? what can you expect?

- 4 basic classes, plus extras like druid, animalkin, and mystic
- b/x math, using descending armor class, and dodge rolls
- low fantasy setting and a copper piece standard
- relative distances and zones for theater of the mind
- hazard die
- many optional rules to customize your specific table
